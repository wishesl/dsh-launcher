# 插件收藏功能实现方案（本地收藏 + 独立页签 + 分享码）

> 在现有「插件市场」（`MarketView`）基础上新增**收藏**能力：发现页 / 已安装页可收藏与取消收藏，
> 新增独立的「收藏」页签展示收藏插件信息，**存本地、不依赖插件市场目录**（断网也能看、也能装），
> 支持从收藏内直接安装 / 卸载，并提供「生成分享码 / 解析分享码添加收藏」用于跨机器、跨会话迁移收藏列表。
> 本方案为设计稿（路线：复用现有市场基建，不引入新依赖）。

---

## 1. 目标与范围

| 能力 | 说明 |
|---|---|
| 收藏 / 取消收藏 | 「发现」卡片与「已安装」行均提供 ★ 开关，一键收藏 / 取消 |
| 独立「收藏」页签 | 与「发现 / 已安装」平级的第三个页签，展示收藏插件的本地快照信息 |
| 本地持久化 | 收藏写入 `%APPDATA%\DSHLauncher\favorites.json`，与插件市场目录抓取完全解耦 |
| 收藏内安装 / 卸载 | 复用现有 `InstallPlugin / UninstallPlugin` + `dsh:market-log` 进度流与右栏自动弹出 |
| 生成分享码 | 把当前收藏列表编码为一段可复制粘贴的文本（`DSH-FAV:v1:…`） |
| 解析分享码 | 粘贴分享码 → 预览 → 确认 → 合并进本地收藏（去重），随后可一键安装 |

不在本期范围（记录为后续方向）：收藏分组 / 备注 / 排序、云端同步、分享码二维码图片、从收藏批量安装、
「只允许目录内插件」的严格白名单开关。

## 2. 需求拆解

```
收藏 = 一份【不依赖目录的本地快照】 + 【可直接安装的安装目标】
  ├─ 快照：name / owner / category / description(zh+en) / stars / downloads / addedAt
  │         → 断网时收藏页签仍可完整渲染（离线可看）
  ├─ 安装目标：install（pnpm target，收藏时由服务端从可信数据推导）
  │         → 断网时也能从收藏直接安装（离线可装，见 §6 安全策略）
  └─ 身份 id：npm 名（优先）或 owner/repo（兜底）
        → 目录刷新、来源切换后收藏仍稳定去重
```

三个入口统一收口到同一套后端 `favorites.go`，前端只负责收集展示用的元数据并触发动作。

### 关键决策

| # | 决策 | 理由 |
|---|---|---|
| F1 | 收藏存 `%APPDATA%\DSHLauncher\favorites.json`，**不放进 profile / `.dsh-market`** | 收藏是启动器用户数据、与实例 profile 解耦，换 `DSH_HOME` 或重装 profile 不丢；与 settings.json 同一持久化模式（MkdirAll + WriteFile） |
| F2 | 收藏是**自包含快照**（含 install 目标），断网可渲染、可安装 | 满足「不依赖插件市场」；目录只作为可选的交叉校验 |
| F3 | install 目标一律由**服务端推导或复验**，前端不传裸包名进命令 | 延续现有「服务端从可信数据推导」的安全边界（见 §6） |
| F4 | 收藏页签的安装/卸载完全复用现有 `marketOp` 流程 | 自动弹右栏「市场任务」、单飞互斥、可取消、toast 反馈全部免费获得 |
| F5 | 分享码格式 `DSH-FAV:v1:<base64url(JSON)>` | 无 `+/=` 等 URL 不安全字符，复制粘贴稳定；Go `encoding/base64.RawURLEncoding` 一行编解码，无需引第三方库 |

## 4. 数据模型与本地存储

```ts
// frontend/src/types.ts 新增
interface FavoritePlugin {
  id: string;             // 身份键：npm 名（优先）或 小写 owner/repo（兜底）
  name: string;           // 展示名（目录 display name，或 npm/包名）
  owner: string;
  url: string;            // GitHub 目录 url（已装来源无目录条目时可为 ""）
  npm: string | null;     // npm 包名（优先安装源）
  install: string;        // pnpm 安装目标：npm 名 或 github:owner/repo[#path:/sub] —— 服务端推导/复验
  source: 'catalog' | 'installed'; // 收藏来源（决定安装时的校验策略）
  category: string;
  description: Record<string, string>; // zh / en 本地化快照
  stars?: number | null;
  downloads?: number | null;
  addedAt: string;        // 本地收藏时间（ISO）
}

// AddFavorite 的入参（前端只传展示元数据，id/install 由后端算）
interface FavoriteDraft {
  name: string; owner: string; url: string; npm: string | null;
  category: string; description: Record<string, string>;
  stars?: number | null; downloads?: number | null;
  source: 'catalog' | 'installed';
  spec?: string;          // source=installed 时传 profile package.json 里的 spec
}

// 分享码解析结果
interface ShareImportResult {
  imported: FavoritePlugin[]; // 本次新增
  skipped: string[];          // 已存在被跳过的 id
}
```

文件结构（`favorites.json`）：

```json
{
  "version": 1,
  "favorites": [ { "id": "@liustack/modlens", "name": "modlens", "owner": "liustack",
      "url": "https://github.com/liustack/modlens", "npm": "@liustack/modlens",
      "install": "@liustack/modlens", "source": "catalog", "category": "tools",
      "description": {"zh": "…", "en": "…"}, "stars": 210, "downloads": 4800,
      "addedAt": "2026-08-26T10:00:00+08:00" } ]
}
```

- 读写走独立 `sync.Mutex`；文件缺失/损坏 → 视为空列表（不报错，与 `readInstalledPlugins` 风格一致）。
- 写盘：`MkdirAll` + `WriteFile`，与 settings 一致；文件小（KB 级），无需原子替换。

## 5. 收藏身份与去重

```go
// favoriteID 返回稳定身份键
func favoriteID(p FavoritePlugin) string {
    if p.NPM != nil && *p.NPM != "" { return *p.NPM }        // npm 名优先
    if repo := repoOf(p.URL); repo != "" { return repo }     // 否则 owner/repo 小写
    return strings.ToLower(strings.TrimSpace(p.Name))        // 兜底
}
```

- `AddFavorite` 按 `favoriteID` 去重（已存在 → 更新快照但保留原 `addedAt`，不重复插入）。
- `RemoveFavorite(id)` 按身份键删除。
- 目录刷新后：收藏的 `url/npm` 不变 → 身份稳定，不会因目录条目改名/换顺序而重复。

## 6. 后端设计（新增 `favorites.go`）

### 6.1 绑定方法清单

```go
// favorites.go
func (a *App) ListFavorites() ([]FavoritePlugin, error)          // 读本地文件（纯本地，无网络）
func (a *App) AddFavorite(d FavoriteDraft) ([]FavoritePlugin, error)  // 服务端推导 id/install → 去重写入
func (a *App) RemoveFavorite(id string) ([]FavoritePlugin, error)     // 按身份键删除
func (a *App) GenerateShareCode() (string, error)                    // 全部收藏 → DSH-FAV:v1:…
func (a *App) ImportShareCode(code string) (*ShareImportResult, error) // 解析+复验+去重合并
func (a *App) InstallFavorite(instanceID string, fav FavoritePlugin) (*MarketOpResult, error) // 收藏内安装
```

### 6.2 `install` 目标的推导 / 复验（F3）

- `source=catalog`：`install, ok := installTargetFor(d.URL, d.NPM)`，`!ok` → 拒绝（与发现页同款推导，不信任前端）。
- `source=installed`：`install = d.Spec`，复验通过 `targetRe`，且是 npm 名（`npmNameRe`）或
  `github:owner/repo`（`repoRe` 前缀 `github:`）或 git+https allowBuilds 键（`gitAllowKeyRe`）三者之一；
  不通过 → 拒绝。
- `InstallFavorite` 每次调用再对存储的 `fav.Install` 复验一次同款正则（防御文件被手工改坏），
  并尝试用现有 `FetchMarketCatalog(false)` 做**可选的交叉校验**：目录可达时，若该 install/npm/repo 对不上
  任何条目则仅**提示**（日志一行），不阻断（离线可装是本期硬需求，见 §6.3 安全策略）。

### 6.3 安全策略（相对发现页白名单的说明）

| 场景 | 策略 |
|---|---|
| 来自目录的收藏 | install 由服务端 `installTargetFor` 从已验证目录条目推导（同发现页） |
| 来自已装的收藏 | install 取自该插件真实 spec，服务端用 shell-safe 正则复验 |
| 分享码导入 | 每个条目的 url/npm/install 逐项复验同款正则后才入库；坏 base64 / 坏前缀 / 坏 JSON 整体拒绝 |
| 命令注入面 | 目标串永远过 `targetRe`（`^[A-Za-z0-9@:./_#+~^=-]+$`），杜绝 shell 元字符进命令行 |
| 与发现页的区别 | 发现页额外要求"当前必须在目录内"；收藏页允许**离线安装**，因此目录交叉校验降级为提示而非阻断 |

说明：收藏目标都是后端自己先前校验过、或用户真实安装过的数据；复验保证无 shell 注入与路径穿越。
用户收藏即显式授权安装。若后续想收紧，可加「仅允许目录内插件」设置开关（列入后续方向）。

### 6.4 重构 `market_ops.go`

把 `InstallPlugin` 中「目录白名单 + 目标推导」之后的部分抽成共享内部函数，供 `InstallFavorite` 复用，
避免双份命令执行/状态机逻辑漂移：

```go
// 共享预检：实例存在 + 版本合法 + 未运行（返回 *Instance）
func (a *App) preflightMarketOp(instanceID string) (*Instance, error)

// 共享安装执行：fast-start running 状态 → 日志 → runMarketCommand → parseIgnoredBuilds → 结果
func (a *App) runInstall(inst *Instance, target string) (*MarketOpResult, error)

// InstallPlugin（保持签名不变）：
//   目录白名单 + findRegistryEntry + installedAlias 去重 → installTargetFor → runInstall
// InstallFavorite：
//   fav.Install 正则复验 + 可选目录交叉校验(仅提示) → runInstall
```

卸载无需新方法：收藏页签直接复用现有 `UninstallPlugin(instanceID, name)`。

### 6.5 分享码格式与解析

```
DSH-FAV:v1:<base64url(JSON, 无 padding)>
```

JSON 载荷（v1）：

```json
{
  "app": "dsh-launcher",
  "v": 1,
  "createdAt": "2026-08-26T10:00:00+08:00",
  "plugins": [
    { "id": "@liustack/modlens", "name": "modlens", "url": "https://github.com/liustack/modlens",
      "npm": "@liustack/modlens", "install": "@liustack/modlens",
      "category": "tools", "description": {"zh": "…", "en": "…"} }
  ]
}
```

- **生成**：`GenerateShareCode` 读收藏 → 组装载荷 → `base64.RawURLEncoding.EncodeToString(json)` → 拼前缀。
- **解析**：`ImportShareCode` 校验前缀 `DSH-FAV:v1:` → base64 解码 → JSON 解析 → 每个插件
  `install` 复验（§6.3）→ 按 `favoriteID` 与现有收藏去重 → 合并写盘，返回 `imported / skipped`。
- 载荷仅含公开插件元数据，**不含任何路径 / 凭证 / 实例信息**，可安全分享。

## 7. 前端设计（React + TS）

### 7.1 页签与入口

- `MarketView` 的 `tab` 扩展为 `'discover' | 'installed' | 'favorites'`，第三个页签文案
  `收藏${favorites.length ? \` (${favorites.length})\` : ''}`。
- 状态 `favorites: FavoritePlugin[]` 存于 `MarketView`（唯一消费方，无需提升到 App；若未来跨视图再提升）。
  挂载时 `loadFavorites()`（`api.listFavorites()`，纯本地、与目录抓取并行失败互不影响）。

### 7.2 发现页 / 已装页的 ★ 开关

- 发现卡片 `plugin-actions` 左侧加星标按钮：实心 ★（已收藏）/ 空心 ☆；点击 `AddFavorite` / `RemoveFavorite`。
- 已装行 `installed-actions` 加星标按钮；点击收藏时优先用 `findCatalogEntry(p, catalog)` 命中目录条目 →
  `source='catalog'`（携带 url/npm，可被目录交叉校验）；命中不到 → `source='installed'` + `spec=p.spec`。
- 星标状态用 `useMemo(new Set(favorites.map(f => f.id)))` 计算，防抖不需要（单次点击即本地写盘，毫秒级）。

### 7.3 收藏页签

- 工具栏：`刷新` + `生成分享码` + `解析分享码`；沿用 `market-toolbar`。
- 卡片网格：复用 `plugin-card` 结构 + 展示 `来源` 徽标（收藏自目录 / 收藏自已装）+ `addedAt` 时间 +
  右侧操作：`取消收藏`；安装态复用 `installedNames`（按 npm/名/repo 匹配）→ 未装 `安装` / 已装 `卸载`。
- 安装 / 卸载动作**直接复用**现有 `install()` / `uninstall()` 函数与 `marketOp` 流程
  （自动弹右栏「市场任务」、单飞互斥、toast 反馈、完成后 `loadInstalled()` 刷新）。
  收藏页签的安装统一走 `api.installFavorite(targetId, fav)`。
- 空态：`还没有收藏的插件，可在「发现」或「已安装」页点击 ★ 收藏`。

### 7.4 分享码面板（内联，非覆盖层）

沿用现有 `log-hint` 内联展开模式，**不做 overlay 弹层**（符合 AGENTS.md 三栏常驻列约定）：

- **生成**：点击后 `api.generateShareCode()` → 内联面板展示只读 `<textarea>`（可全选复制）+
  `复制`（`navigator.clipboard.writeText`）+ `收起`。
- **解析**：点击后内联面板展示 `<textarea>`（粘贴）+ `解析`；解析成功 → 预览行
  「可添加 N 个，已存在跳过 M 个」+ 各插件名列表 + `确认添加` / `取消`；
  `api.importShareCode(code)` → toast「已添加 N 个收藏」→ 刷新 favorites。
- 面板内错误（坏前缀 / 坏编码 / 空）以 `log-hint-err` 红字就地展示。

### 7.5 api.ts / types.ts 增量

```ts
// api.ts
listFavorites(): Promise<FavoritePlugin[]>      // ListFavorites
addFavorite(d: FavoriteDraft): Promise<FavoritePlugin[]>   // AddFavorite
removeFavorite(id: string): Promise<FavoritePlugin[]>      // RemoveFavorite
generateShareCode(): Promise<string>            // GenerateShareCode

```

## 8. 与现有模块的集成点

| 现有模块 | 复用方式 |
|---|---|
| `market_ops.go` InstallPlugin | 抽 `preflightMarketOp` / `runInstall` 共享；`InstallFavorite` 复用 |

| `Sidebar` / 三栏布局 | 无改动——收藏只是市场页内第三个页签，不新增导航项 |

## 10. 测试要点

- 单测（沿用现有 `_test.go` 风格，可注入文件路径）：
  - `favoriteID`：npm 优先、repo 兜底、大小写归一；
  - Add/Remove 持久化往返（写→读→删→读）；
  - AddFavorite 的 install 推导：catalog 来源命中 `installTargetFor`；installed 来源 spec 合法/非法各例；
  - `ImportShareCode`：合法码 / 坏前缀 / 坏 base64 / 坏 JSON / 含非法 install 条目 / 重复跳过 / 空列表；
  - `GenerateShareCode → ImportShareCode` 往返一致；
  - `InstallFavorite`：target 白名单拒绝样例；目录不可达时仍可安装（离线路径）。
- 手工验收：目录可达与断网两种环境下各收藏 2 个插件（一个目录来源、一个已装来源），
  验证收藏页渲染、安装/卸载、分享码生成-解析-合并全链路；断网下收藏页可读、可装。
- 构建收尾按 AGENTS.md：`cd dsh-launcher/frontend && npm run build` + `cd dsh-launcher && wails build`。
